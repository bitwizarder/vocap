## 📖 About the Project

**Vocap** is a powerful, completely offline subtitle studio for Android. It leverages on-device AI to transcribe speech, edit timelines, style subtitles with custom fonts, and export videos with burned-in captions — **all without sending a single byte of your data to the cloud.**

> [!NOTE]
> Internet is only required once to download the offline Whisper AI models. After that, the app works flawlessly in airplane mode.

## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| 🔒 **100% Private** | No servers, no tracking, no data collection. |
| 🎙️ **Offline Speech-to-Text** | Integrated Whisper AI models for highly accurate transcription. |
| 🎬 **Advanced Timeline** | Pinch-to-zoom, split/merge segments, and 50-step undo/redo. |
| 🌍 **Bilingual Subtitles** | Manage dual-language tracks with independent styling. |
| 🎨 **Custom Styling** | Built-in Persian/Arabic/Latin fonts plus support for custom `.ttf`/`.otf`. |
| 🚀 **Fast Export** | Render MP4 with burned-in subtitles, or export SRT/VTT/ASS. |

## 🛠️ Tech Stack & Licenses

- **Media Engine:** FFmpeg (LGPL)
- **Speech Recognition:** Whisper (MIT)
- **UI/UX:** Built with a focus on RTL and accessibility.
