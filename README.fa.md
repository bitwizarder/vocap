## 📖 درباره پروژه

اپلیکیشن **Vocap** یک استودیوی قدرتمند و کاملاً آفلاین برای زیرنویس‌گذاری ویدیوهاست. با استفاده از هوش مصنوعی روی دستگاه، گفتار را به متن تبدیل می‌کند، امکان ویرایش تایم‌لاین، استایل‌دهی با فونت‌های دلخواه و خروجی ویدیو با زیرنویس چسبیده را فراهم می‌کند؛ **بدون اینکه حتی یک بایت از اطلاعات شما به سرور ارسال شود.**

> [!NOTE]
> اینترنت فقط یک بار برای دانلود مدل‌های هوش مصنوعی Whisper لازم است. پس از آن، برنامه حتی در حالت پرواز (Airplane Mode) نیز به خوبی کار می‌کند.

## ✨ ویژگی‌های کلیدی

| ویژگی | توضیحات |
| :--- | :--- |
| 🔒 **حریم خصوصی ۱۰۰٪** | بدون سرور، بدون ردیابی و بدون جمع‌آوری داده. |
| 🎙️ **تبدیل آفلاین گفتار به متن** | یکپارچه با مدل‌های Whisper برای دقتی بالا. |
| 🎬 **تایم‌لاین پیشرفته** | بزرگ‌نمایی دو انگشتی، تقسیم/ادغام سطرها و ۵۰ مرحله بازگشت. |
| 🌍 **زیرنویس دوزبانه** | مدیریت هم‌زمان دو زبان با استایل‌دهی کاملاً مستقل. |
| 🎨 **استایل و فونت دلخواه** | فونت‌های داخلی فارسی/عربی/لاتین + پشتیبانی از فایل‌های `.ttf`/`.otf`. |
| 🚀 **خروجی سریع** | رندر MP4 با زیرنویس چسبیده یا خروجی SRT/VTT/ASS. |
